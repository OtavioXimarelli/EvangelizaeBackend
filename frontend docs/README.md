# Frontend Requirements Pack (for Java Backend)

Use these files to implement the backend with the exact frontend contract:

1. `prd-frontend-to-backend.md` — product requirements and acceptance criteria.
2. `frontend-api-contract.md` — request/response contracts expected by frontend code.
3. `openapi-frontend-contract.yaml` — machine-readable API contract baseline.
4. `enum-mapping.json` — canonical enum/value mapping used by frontend adapters.
5. `frontend-feature-gap-analysis.md` — migration gaps and sequencing.
